# Agent Users are the only outlet for judgement

The system presents objective relationships within a User's own records but never issues a conclusion of its own (see the *System Never Judges* principle in `CONTEXT.md`). Any judgement in the product — an Expectation Outcome, a reasoning assessment, a pattern claim, a periodic analysis — must be attributed to an identifiable owner: the human User who wrote it, or an Agent User. An Agent User is thus the only legitimate outlet for AI judgement. Its conclusions are its own owned records, are surfaced as that Agent's view rather than as system fact, and are never written back onto a human User's records.

This makes one product commitment hold across otherwise separate features. In the first version a human User provisions their own Agent to act as a parallel observer or a self-directed reviewer over granted records. A later membership feature that ships built-in AI analysis (for example a weekly or monthly report) is the same mechanism with an official owner: the report is that platform-operated Agent's record, labelled as its view, not a verdict spoken by the product. Because the outlet is identical, the neutrality principle survives the introduction of built-in AI.

To keep that path open without a later identity rewrite, the Agent User ownership model must not hard-code that every Agent is provisioned by a human User. First-version behavior only needs human-provisioned Agents, and Access Grants remain restricted to Agents the granting human provisioned (see ADR-0004). But the identity schema and authorization checks must be able to represent a platform-operated Agent as an owner. The cost is that Agent identity carries a provisioning dimension the first version does not fully exercise; the benefit is that the neutrality guarantee and the built-in-AI roadmap share one architecture instead of two.

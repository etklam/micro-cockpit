# 03 — 搜尋與瀏覽歷史市場觀察

**What to build:** 讓使用者從 Today、Calendar 與 Subject／Instrument 時間線找回目前保留的市場觀察，而不建立另一套 archive 或 Research Timeline。

**Blocked by:** 02 — 結構化 Observation Update

**Status:** ready-for-agent

- [ ] Today 提供「所有觀察」入口而不新增獨立主導覽項目
- [ ] 歷史搜尋支援日期、內容、Observation Subject、Instrument、Tag 與作者篩選
- [ ] 搜尋結果使用穩定 cursor pagination，並維持 User ownership isolation
- [ ] Calendar 第一版以 Market Observation 與 review readiness 為主，不顯示舊 Performance surface
- [ ] 使用者可從 Subject 或 Instrument 查看跨 Journal Day 的 Observation Update 時間線
- [ ] 搜尋與時間線只連到目前保留的內容，不宣稱具有版本歷史
- [ ] 覆蓋 filter 組合、pagination、empty/error state 與手機瀏覽流程

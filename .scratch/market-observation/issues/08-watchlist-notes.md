# 08 — 建立 Watchlist 與 Watchlist Note

**What to build:** 讓使用者明確選擇持續觀察的 Instrument，保存簡短關注原因，並快速進入該 Instrument 的市場觀察時間線。

**Blocked by:** 02 — 結構化 Observation Update

**Status:** completed

- [x] 使用者可新增或移除 Watchlist Instrument
- [x] Watchlist UI 與 API 不使用 portfolio、holding、position 或 buy-list 語意
- [x] 每個 Watchlist member 可保存簡短且可修改的 Watchlist Note
- [x] Watchlist Note 用於關注原因，不取代 Observation Update、Expectation 或 Research Timeline
- [x] 使用者可從 Watchlist 開啟 Instrument 的跨日觀察時間線
- [x] Watchlist membership 使 Instrument 保持 Tracked Instrument 狀態
- [x] 覆蓋 duplicate membership、ownership、note validation 與手機畫面

# 02 — 結構化 Observation Update

**What to build:** 讓使用者把 Quick Observation 漸進補充為可搜尋、可檢討的市場觀察，同時保持 Signal、Interpretation、Subject 與一般 Tag 的語意邊界。

**Blocked by:** 01 — 建立 Journal Day 與 Quick Observation

**Status:** completed

- [x] Observation Update 可加入一個主要 Observation Subject 與多個相關 Subject
- [x] Subject 支援 broad market、sector、theme 與 Instrument
- [x] 美股 Instrument 從系統目錄選擇，並以穩定身分保留 symbol history
- [x] 其他市場可手動輸入 market、symbol 與 display name，並標示未提供 Daily Close
- [x] 使用者可分開填寫 Signal 與 Interpretation
- [x] 使用者可加入 Tag 與可選 Mental State，系統不自動推斷或分類
- [x] 第一版證據支援 URL、title 與使用者摘錄，不抓取全文或接受檔案上傳
- [x] 覆蓋 enrichment validation、Instrument identity、ownership 與雙語畫面

# 02 — Responsive save path（後端 fan-out 並行 + 前端樂觀更新）

**What to build:** 讓主要「捕捉／儲存」路徑變快、變順——(a) 後端 journal-service 對 market-data-service 的 daily-close / instrument-resolve fan-out 從逐個串行 `await` 改為 `Task.WhenAll` 並行，保留既有優雅降級；(b) 前端對高頻儲存動作加 TanStack Query 樂觀更新，消除儲存後 loading 閃爍與重跑慢路徑。兩者有乘數效果，建議一氣呵成。

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] 後端 `AttachDailyCloseAsync`：primary + 所有 related 的 `Attach` 用 `Task.WhenAll` 並行，結果依原順序回填，response shape 不變。
- [x] 後端 `ResolveAsync`：primary + related 並行；**保留「primary 出錯即早回（短絡）」語意**（先等 primary，成功後再 fan-out related；或等價策略）——不改錯誤優先級，只改並行度。

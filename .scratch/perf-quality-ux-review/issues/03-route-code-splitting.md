# 03 — Route-level code-splitting

**What to build:** 用 React Router 7 原生 `lazy()` + `<Suspense>` 做路由級 code-splitting，並用 `manualChunks` 把 react-markdown / remark 切成獨立 chunk，讓 Landing / 登入頁不必先載整個已登入 app。

**Blocked by:** None — can start immediately.（Soft edge with 01：lazy chunk 載入失敗應可被 01 的 Error Boundary 接住——lazy + Suspense + ErrorBoundary 標準組合。兩者協調 fallback 即可，不需硬性 block。）

**Status:** completed

- [x] 頂層路由改 `lazy()` + `<Suspense fallback={…}>`（landing/login 與 authenticated 區塊為自然分割點）；fallback 用 skeleton／輕量占位，不用動畫 spinner，尊重 `prefers-reduced-motion`（既有 `index.css:338` 已有 media query）。
- [x] `vite.config.ts` 加 `build.rollupOptions.output.manualChunks`，把 react-markdown / remark 系列獨立成 chunk（只在渲染 markdown 的頁才載）。
- [x] `npm run build` 後主 chunk 顯著縮小；Landing / 登入路徑初始 JS 下載量下降。
- [x] 路由切換不破壞既有行為：auth redirect、appearance/locale reconcile、scroll-to-top。
- [x] 驗證：`npm run build` 確認多 chunk 產出與各 chunk gz size 合理；首次造訪 `/` 與 `/login` 只下載所需 chunk，進 `/today` 才載 app chunk；外觀/locale 切換、auth 流程不受影響。

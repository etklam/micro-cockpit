**What to build:** 三個獨立但同屬「可靠性／精準／節制」的前端品質修復，一次掃完——(a) 全站頂層 React Error Boundary，避免 render-time 例外造成白畫面並提供恢復路徑；(b) Today 頁問候語改用帳號時區而非裝置本地時；(c) 統一全站「載入中」為 skeleton pattern，移除散落的純文字 loading。

**Blocked by:** None — can start immediately.

**Status:** completed
